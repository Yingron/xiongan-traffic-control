# Xiongan Traffic Control API 接口文档

## 1. 概述

本文档定义了雄安新区交通信号控制平台的API接口，包括WebSocket实时通信接口和RESTful API接口。

## 2. WebSocket接口

### 2.1 连接地址

```
ws://localhost:8765
```

### 2.3 命令列表

| 命令 | 说明 | 参数 |
|------|------|------|
| `start` | 启动仿真 | 无 |
| `stop` | 停止仿真 | 无 |
| `reset` | 重置仿真 | 无 |
| `step` | 执行步进 | `steps`: 步数 |
| `predict` | 执行动作 | `action_value`: 0-3 |
| `get_state` | 获取状态 | 无 |
| `set_scenario` | 设置场景 | `scenario`: morning_peak/noon_offpeak/evening_peak |

## 3. RESTful API接口

### 3.1 基础地址

```
http://localhost:8000/api/
```

### 3.2 仿真控制接口

#### POST /api/simulation/start

启动仿真

**响应**:
```json
{"status": "success", "message": "Simulation started"}
```

#### POST /api/simulation/stop

停止仿真

**响应**:
```json
{"status": "success", "message": "Simulation stopped"}
```

#### POST /api/simulation/reset

重置仿真

**响应**:
```json
{"status": "success", "message": "Simulation reset"}
```

#### POST /api/simulation/step

执行步进

**参数**:
- `steps`: 步数（默认1）

**响应**:
```json
{"status": "success", "simulation_time": 3600}
```

### 3.3 动作执行接口

#### POST /api/simulation/action

执行信号控制动作

**请求体**:
```json
{
  "intersection_id": "J1",
  "phase": 0
}
```

**响应**:
```json
{"status": "success", "phase": 0, "reward": -5.2, "simulation_time": 3600}
```

### 3.4 状态查询接口

#### GET /api/simulation/state

获取当前仿真状态

**响应**:
```json
{
  "timestamp": 1234567890,
  "simulation_time": 3600,
  "intersections": [...],
  "vehicles": [...],
  "metrics": {...}
}
```

### 3.5 模型接口

#### POST /api/model/load

加载预训练模型

**参数**:
- `model_type`: dqn/d3qn（默认d3qn）

**响应**:
```json
{"status": "success", "model": "d3qn"}
```

#### POST /api/model/predict

使用模型预测动作

**响应**:
```json
{"action": 0, "phase": 0}
```

### 3.6 场景接口

#### POST /api/scenario/set

设置交通场景

**请求体**:
```json
{"scenario": "morning_peak"}
```

**响应**:
```json
{"status": "success", "scenario": "morning_peak"}
```

### 3.7 健康检查

#### GET /api/health

健康检查

**响应**:
```json
{"status": "healthy", "env_running": true}
```

## 4. 数据类型定义

### 4.1 信号相位

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | NS_Straight | 南北直行 |
| 1 | NS_LeftTurn | 南北左转 |
| 2 | EW_Straight | 东西直行 |
| 3 | EW_LeftTurn | 东西左转 |

### 4.2 交通场景

| 场景 | 时间段 | 流量特征 |
|------|--------|---------|
| morning_peak | 7:00-9:00 | 北向流入为主 |
| noon_offpeak | 11:00-14:00 | 流量均衡 |
| evening_peak | 17:00-19:00 | 南向流出为主 |

## 5. 错误码

| 错误码 | 说明 |
|--------|------|
| 400 | 仿真未启动 |
| 404 | 模型文件未找到 |
| 500 | 服务器内部错误 |

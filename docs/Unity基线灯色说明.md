# Unity 基线灯色说明

## 适用范围

本文只说明 `python server/visualization_server.py --no-model` 的固定配时演示。DQN 推理模式使用 30 路口正式的 `rl4` 四相位动作，不受本说明所述旧问题影响。

## 旧网络的视觉差异

旧版 `xiongan_30.net.xml` 为每个路口同时保留 `rl4` 与 `programID="0"` 两个同名信号程序。其中旧 `program 0` 的相位 1、3 是黄灯过渡；Unity 的简化灯色映射却把相位 1、3 解释为左转绿灯。因此，旧基线演示中可能出现“SUMO 正在黄灯、Unity 看起来是左转绿灯”的视觉差异。

这只影响基线对比的灯色细节：不会改变 SUMO 的行驶状态、统计指标或 DQN 决策结果。

## 当前处理

- 正式 `xiongan_30.net.xml` 仅保留每个 J01--J30 信号灯的 `rl4` 四相位程序；
- 可视化服务启动时显式执行 `setProgram(tl_id, "rl4")`，不再依赖 SUMO 默认选择；
- `--no-model` 仍作为固定配时基线使用，DQN 模式则按 30 个路口的模型动作实时控制。

录制对比视频时，基线画面可标注为“固定配时（`rl4`）”，不应把历史 `program 0` 的黄灯视觉当作算法行为差异。

# 雄安20路口 v3 Fixed

本版本专门修复原 v3 的接口兼容问题：

- J01—J20 全部是可控 `traffic_light`，不再有 `dead_end`；
- 20 个路口全部严格统一为 4 个可控相位；
- 道路改为双向，并为边界路口补齐外围进口/出口；
- 所有核心路口均为四进口、四出口；
- 进口车道按 N/S/E/W 自动生成映射；
- 后端动作顺序固定为 J01 → J20，一次接收 20 个动作；
- 提供早高峰、平峰、晚高峰三套交通流。

## 第一次使用

1. 双击 `生成并验证.bat`。
2. 看到“验证通过”后，双击 `启动早高峰.bat`。
3. 给 A/C 同学的接口文件在 `docs/`：
   - `interface_contract.json`
   - `lane_mapping.json`
   - `tls_mapping.json`
   - `compatibility_report.md`

## 动作定义

- 0：南北直行及右转
- 1：南北保护左转
- 2：东西直行及右转
- 3：东西保护左转

注意：为了满足项目现有“每路口统一4动作”的硬接口，本版本的 `tlLogic` 恰好包含 4 个 phase，不额外插入黄灯 phase。后续如要提高交通安全真实性，应在环境控制器中用过渡逻辑处理黄灯，而不要改变动作空间大小。

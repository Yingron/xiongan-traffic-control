# 30路口比赛演示运行手册

## 演示链路选择

主展示采用现有且最稳定的链路：

```text
frontend/pymarl --TCP 5000--> frontend/CitySimulation
```

Unity负责30路口场景、车辆、信号和指标展示，PyMARL通过长度前缀JSON协议执行
`init/reset/step/close`。C后端的REST/WebSocket服务作为独立能力展示：

```text
客户端 --REST/WebSocket 8000--> server/api_server.py --TraCI--> SUMO xiongan_30
```

端口8765仅用于SUMO可视化协议，不与上述两条会话混用。正式DQN权重未交付前，
不得把固定动作或随机动作描述成模型预测。

## Unity主演示

1. Unity 2022.3.62f2打开 `frontend/CitySimulation`；
2. 打开 `Assets/Scenes/City.unity`；
3. 点击Play，等待日志出现120条道路、30/30信号灯和TCP 5000启动；
4. 在仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_unity_smoke_test.ps1
```

5. 在Game视图展示完整30路口、信号灯、车辆及运行面板；
6. 需要观察时使用侧栏fold按钮收起或展开控制面板。

2026-08-13实机验收已通过：Unity返回30个联合智能体、510维状态，连续执行3步并
返回有效奖励。后续可重复运行同一脚本作演示前检查。

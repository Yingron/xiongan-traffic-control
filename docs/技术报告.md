## 1. 项目概述

### 1.1 项目背景

随着雄安新区“窄路密网”城市规划理念的推进，传统定时信号控制已难以适应复杂多变的交通需求。本项目基于深度强化学习技术，开发面向雄安新区的自适应交通信号控制算法，并构建完整的仿真验证平台。

### 1.2 赛题要求

- 赛道C：AI应用型——自适应交通信号控制
- 核心指标：模型体积<1MB，推理延迟<5ms
- 路网规模：≥20个路口

### 1.3 技术路线

```
SUMO仿真核心 → Python算法层 → Unity可视化层
```

## 2. 系统架构设计

### 2.1 三层协同架构

| 层级 | 技术选型 | 核心职责 |
|------|---------|---------|
| Unity可视化层 | Unity 3D + C# WebSocket | 高保真展示、数据仪表盘、交互控制 |
| Python算法层 | Python + PyTorch + SB3 | DQN训练、模型量化、推理、数据分析 |
| SUMO仿真层 | SUMO + TraCI + libsumo | 交通流仿真、路网建模、信号执行 |

### 2.2 数据流设计

```
Unity ↔ Python ↔ SUMO
   ↕              ↕
WebSocket     TraCI协议
```

### 2.3 接口设计

#### 2.3.1 状态空间（26维）

| 维度范围 | 含义 | 数量 |
|---------|------|------|
| 0-3 | 相位编码（One-hot） | 4 |

|----|------|
| 0 | 南北直行 |

## 3. DQN算法实现

### 3.1 DQN网络结构

```
输入(26) → 隐藏层1(256) → 隐藏层2(256) → 输出(4)
```

### 3.2 奖励函数设计

```python
reward = w1*(-queue) + w2*(-max_wait) + w3*(throughput) + w4*(-switch) + w5*(-overflow)
```

其中：
- `w1=0.1`：排队长度权重
- `w2=0.5`：公平性权重（最大等待时间）
- `w3=0.2`：吞吐量权重
- `w4=1.0`：切换惩罚
- `w5=5.0`：溢出惩罚

### 3.3 训练参数

| 参数 | 值 |
|------|----|
| 学习率 | 1e-4 |
| 批大小 | 64 |
| γ (折扣因子) | 0.99 |
| 探索率 | 1.0 → 0.05 |
| 目标网络更新 | 10000步 |
| 总训练步数 | 1000000 |

## 4. 模型轻量化方案

### 4.1 知识蒸馏

- 教师模型：DQN（256×256隐藏层）
- 学生模型：轻量网络（64×64隐藏层）
- 蒸馏温度：2.0
- 蒸馏权重α：0.7

### 4.2 模型量化

- 量化方式：PyTorch动态量化（INT8）
- 量化对象：nn.Linear层
- 输出格式：TorchScript

### 4.3 轻量化目标

| 指标 | 目标值 |
|------|--------|
| 模型体积 | < 1MB |
| 推理延迟 | < 5ms |
| 精度损失 | < 15% |

## 5. 仿真环境构建

### 5.1 路网结构

- 规模：7路口网格布局（可扩展至20+）
- 道路类型：城市道路，双向单车道
- 速度限制：50km/h（13.89m/s）

### 5.2 交通流配置

| 时段 | 流量特征 |
|------|---------|
| 早高峰(7-9点) | 南北向为主，流量最大 |
| 平峰(11-14点) | 流量均衡 |
| 晚高峰(17-19点) | 南向流出为主 |

### 5.3 检测器配置

- 环形检测器（e1Detector）：采集排队长度、占有率
- 进出检测器（entryExitDetector）：统计通过车辆数
